# 📚 Learning Progress Dashboard

A simple web application built using **HTML, CSS, and JavaScript** to evaluate a student's learning progress based on topics completed, practice hours, and confidence rating.

##  Features

- Student Progress Form
- Input Validation
- Dynamic Progress Report
- Local Storage Support
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript

##  Files

- `index.html`
- `style.css`
- `script.js`

##  How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/shreyasbhagwat96/AWT_TAE_1_JavaScript-Learning-Progress-Dashboard.git
   ```
2. Open `index.html` in your browser.
